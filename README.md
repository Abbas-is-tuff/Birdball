# ⚽🐦 Birdball

A 3D football (soccer) game played by birds, in your browser. Works on iPad, phones and computers. Nothing to install.

**▶️ Play:** https://abbas-is-tuff.github.io/birdball/ (after GitHub Pages is turned on, see below)

Each bird has its own Speed, Shot, Stamina and Keeper stats.

## Rivals

Pigeon Rovers, Penguin Palace, Flamingo FC, Seagull Seaside, Crow City, Owl Athletic, Macaw Kings and Eagle United. They range from easy to hard.

## Game modes

- **Friendly Match**: pick your 7 birds and a rival.
- **⭐ Career**: climb from the Sunday League to the World League. Train with playable drills (graded S–D), travel to away games by bus, train or plane, earn prize money, sign sponsors and win trophies. The top 3 are promoted.
- **🏆 Feather Cup**: five knockout rounds, with golden goal for draws.

## Real football rules

7-a-side with 2 substitutes. The game has throw-ins, corners, goal kicks, fouls, free kicks, penalties, yellow and red cards, offside and added time. A magpie referee runs the match. It also has instant replays after goals, rain matches and live commentary.

## Controls

| Touch | Keyboard | What it does |
|---|---|---|
| Left side joystick | WASD / arrows | Move |
| SHOOT (hold) | Space | Shoot – hold longer for more power |
| PASS | E | Pass to the teammate with the blue ring |
| SWITCH | R | Control a different bird |
| DRIBBLE | F | Skill move: spin and burst, can't be tackled |
| TACKLE | T | Slide tackle (dive when you're the keeper) |
| FLAP | Q | Jump – tap again in the air to fly for headers |
| SPRINT | Shift | Run faster (uses stamina) |
| 🎥 | C | Change camera: Wide, Full pitch or Close |
| ⏸ | P | Pause / substitutions |

## Play it on iPad like an app – even offline 📴

1. Open the game link in **Safari** while you have internet.
2. Tap **Share → Add to Home Screen**.
3. Open Birdball from the Home Screen once while still online, so it saves itself.

Now it works with **no internet**: on a plane, in the car, anywhere. When you're online again, it updates itself automatically.

On a computer you can also just download `index.html` and double-click it. The whole game, including the 3D engine, is inside that one file.

## Turning on GitHub Pages

1. In this repo, go to **Settings → Pages**.
2. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch **main**, folder **/ (root)**, and press **Save**.
3. After a minute the game is live at `https://abbas-is-tuff.github.io/birdball/`.
